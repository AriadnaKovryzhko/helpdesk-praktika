| Набор | Сценарии |
| --- | --- |
| Здоровье сервиса | единый формат ответа и ошибки |

### Тесты компонентов

Страница входа, форма заявки, таймер SLA, действия с заявкой, комментарии с проверкой защиты от XSS, проверка вложений, защита маршрутов, UI-kit, счётчик уведомлений, клиент API с автоматическим обновлением токена.

### Сквозные сценарии

1. Пользователь создаёт заявку, исполнитель получает уведомление без перезагрузки страницы, берёт заявку в работу и решает её, пользователь закрывает заявку, руководитель открывает дашборд и журнал аудита.
2. Пользователю недоступны чужая заявка и панель руководителя.
3. Девять страниц не имеют горизонтальной прокрутки при ширине 360, 768 и 1920 px (три запуска).

## Найденные и исправленные дефекты

| № | Дефект | Как обнаружен | Исправление |
| --- | --- | --- | --- |
| 1 | Регистрация возвращала 404 на пустой базе, потому что нет справочника ролей | интеграционные тесты | seed выполняется перед тестами в CI и при старте контейнера |
| 2 | Ошибка типов при ротации refresh-токена | сборка | уточнён тип параметра |
| 3 | Ошибка типов в блокировке между вкладками браузера | сборка | уточнён тип результата |
| 4 | Управляющие символы в регулярном выражении очистки имени файла | линтер | посимвольная фильтрация |
| 5 | Тест гонки при взятии заявки ожидал только код 409, хотя при завершённом первом запросе верен и 404 | интеграционный тест | тест учитывает оба допустимых исхода |
| 6 | Кнопка «Выйти» почти не видна на тёмном фоне | просмотр экранов | отдельный вариант кнопки для тёмного фона |
| 7 | Графики дашборда появлялись с задержкой и исчезали при изменении размера | просмотр экранов | отключена анимация диаграмм |

| 9 | В данных seed была просрочена большая часть заявок | просмотр дашборда | сроки открытых заявок приведены к реалистичным |
| 10 | Сценарий Playwright находил пункт скрытого списка вместо строки журнала | сквозной тест | уточнён селектор |

## Известные ограничения

- Срок SLA не приостанавливается на время ожидания ответа пользователя и считается в календарном времени.
- Письмо для восстановления пароля не отправляется, ссылка выводится в лог сервера, как предусмотрено спецификацией.
- Docker проверяется только в GitHub Actions, на компьютере разработки он недоступен.
